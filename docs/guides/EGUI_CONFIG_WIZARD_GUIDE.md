# egui 配置向导使用指南

## 概述

egui 配置向导为 egui 原生界面提供了完整的任务管理和配置功能，包括：

- 任务创建向导 - 分步骤创建数据解析、模型生成等任务
- 任务监控 - 实时查看任务执行状态和进度
- 数据库管理 - 启动和管理 SurrealDB 数据库
- 配置编辑 - 编辑和管理 DbOption.toml 配置文件

## 功能模块

### 1. 任务创建向导

任务创建向导提供了四个步骤的向导式界面，帮助用户快速创建各类数据处理任务。

#### 步骤 1: 基础信息

- **任务名称**: 为任务指定一个唯一的名称
- **任务类型**: 选择任务类型
  - 📊 数据解析任务 - 解析 PDMS 数据库文件
  - 🎨 模型生成任务 - 生成 3D 模型和网格
  - 🌳 空间树生成任务 - 构建空间索引树
  - 🔄 全量同步任务 - 全量数据同步
  - ⚡ 增量同步任务 - 增量数据同步
- **任务描述**: 可选的任务描述信息
- **优先级**: 设置任务优先级（低/普通/高/紧急）

#### 步骤 2: 选择站点

- **单选模式**: 选择单个目标站点
- **批量模式**: 选择多个站点批量创建任务
- **测试连接**: 在创建任务前测试站点连接状态

#### 步骤 3: 任务参数

根据选择的任务类型，配置相应的参数：

**数据解析任务参数**:
- 解析模式: 全部解析/指定数据库编号/指定参考号
- 数据库编号: 逗号分隔的数据库编号列表（如 7999,8001,8002）
- 参考号: 单个参考号

**模型生成任务参数**:
- 生成选项: 3D 模型/网格/空间树/布尔运算
- 网格容差比例: 0.001-1.0，默认 0.01
- 最大并发数: 1-32，默认 4
- 并行处理: 启用/禁用

**空间树生成任务参数**:
- 树深度: 1-10，默认 5
- 节点容量: 10-1000，默认 100
- 索引类型: R-Tree/Quad-Tree/Oct-Tree

#### 步骤 4: 预览确认

- 查看完整的任务配置摘要
- 资源需求预估（内存、磁盘、耗时）
- 注意事项提示
- 确认后创建任务

### 2. 任务模板管理

#### 保存模板

1. 在任务创建向导中配置好任务参数
2. 点击"💾 保存为模板"按钮
3. 模板将保存到 `~/.config/egui_remote_sync/task_templates.json`

#### 使用模板

1. 点击"📋 从模板创建"按钮
2. 从模板列表中选择一个模板
3. 模板参数将自动填充到向导中
4. 可以修改参数后创建任务

### 3. 任务监控

任务监控页面提供实时的任务状态查看功能：

#### 任务列表

- 任务名称、类型、状态
- 实时进度条和当前步骤
- 操作按钮（详情/取消/删除）

#### 任务状态

- ⏸️ 等待中 - 任务已创建，等待执行
- 🟢 运行中 - 任务正在执行
- ✅ 完成 - 任务成功完成
- ❌ 失败 - 任务执行失败
- ⚪ 已取消 - 任务被用户取消

#### 任务详情

点击"详情"按钮查看任务的完整信息：
- 任务 ID
- 开始时间和完成时间
- 详细的错误信息（如果失败）
- 当前执行步骤

#### 自动刷新

- 默认启用自动刷新（每 5 秒）
- 可以手动关闭自动刷新
- 点击"🔄 刷新"按钮手动刷新

### 4. 数据库管理

数据库管理页面用于启动和管理 SurrealDB 数据库。

#### 配置参数

- **主机地址**: 默认 localhost
- **端口**: 默认 8000
- **命名空间**: 默认 default
- **数据库**: 默认 default
- **用户名**: 默认 root
- **密码**: 数据库密码
- **数据路径**: 数据存储路径，可以通过文件选择器选择

#### 数据库操作

- **▶️ 启动数据库**: 启动 SurrealDB 进程
- **⏹️ 停止数据库**: 停止 SurrealDB 进程
- **🔍 测试连接**: 测试数据库连接状态
- **💾 保存配置**: 保存配置到 DbOption.toml

#### 数据库状态

- ⚪ 已停止 - 数据库未运行
- 🟡 启动中 - 数据库正在启动
- 🟢 运行中 - 数据库正常运行，显示地址和版本
- 🟡 停止中 - 数据库正在停止
- 🔴 错误 - 数据库启动或运行出错

#### 日志输出

实时显示数据库的启动日志和运行日志，方便排查问题。

### 5. 配置编辑

配置编辑页面提供两种模式编辑 DbOption.toml 配置文件。

#### 表单模式

通过表单界面编辑配置项：

**数据库配置**:
- 数据库路径
- SurrealDB 主机
- SurrealDB 端口

**Web Server 配置**:
- 监听地址
- 监听端口

**其他配置**:
- 日志级别（Trace/Debug/Info/Warn/Error）
- 最大连接数

#### 文本模式

直接编辑 TOML 格式的配置文件，适合高级用户。

#### 配置操作

- **💾 保存配置**: 保存配置到 DbOption.toml
- **🔄 重新加载**: 从文件重新加载配置
- **⚠️ 恢复默认**: 恢复到默认配置

#### 配置验证

保存配置时会自动验证：
- 端口号不能为 0
- TOML 格式正确性
- 配置项完整性

验证失败时会显示详细的错误信息。

## 使用场景

### 场景 1: 创建数据解析任务

1. 打开"任务创建"页面
2. 输入任务名称，选择"数据解析任务"
3. 选择目标站点
4. 配置解析模式和数据库编号
5. 预览确认后创建任务
6. 在"任务监控"页面查看执行进度

### 场景 2: 批量创建模型生成任务

1. 打开"任务创建"页面
2. 输入任务名称，选择"模型生成任务"
3. 启用"批量模式"，选择多个站点
4. 配置生成选项和性能参数
5. 保存为模板以便后续使用
6. 创建任务后在"任务监控"页面查看所有任务

### 场景 3: 启动和管理数据库

1. 打开"数据库管理"页面
2. 配置数据库参数（主机、端口、数据路径等）
3. 点击"启动数据库"
4. 查看日志确认启动成功
5. 使用"测试连接"验证数据库可用性
6. 需要时点击"停止数据库"

### 场景 4: 修改应用配置

1. 打开"配置编辑"页面
2. 选择"表单模式"或"文本模式"
3. 修改需要的配置项
4. 点击"保存配置"
5. 根据提示重启相关服务

## 常见问题

### Q: 任务创建失败怎么办？

A: 检查以下几点：
1. 确认目标站点连接正常
2. 检查任务参数是否正确
3. 查看错误提示信息
4. 确认 Web Server 正在运行

### Q: 数据库启动失败？

A: 可能的原因：
1. 端口被占用 - 修改端口或停止占用进程
2. 数据路径不存在 - 创建目录或选择有效路径
3. SurrealDB 未安装 - 安装 SurrealDB
4. 权限不足 - 使用管理员权限运行

### Q: 任务模板保存在哪里？

A: 任务模板保存在用户配置目录：
- Windows: `C:\Users\<用户名>\AppData\Roaming\egui_remote_sync\task_templates.json`
- macOS: `~/Library/Application Support/egui_remote_sync/task_templates.json`
- Linux: `~/.config/egui_remote_sync/task_templates.json`

### Q: 如何查看任务执行日志？

A: 
1. 在"任务监控"页面点击任务的"详情"按钮
2. 查看错误信息字段
3. 如需更详细的日志，查看 Web Server 的日志输出

### Q: 配置文件格式错误怎么办？

A: 
1. 在"配置编辑"页面点击"恢复默认"
2. 或者手动编辑 DbOption.toml 文件
3. 使用 TOML 验证工具检查格式

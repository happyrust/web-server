# 新功能使用指南

## 概述

本指南介绍 egui 异地协同运维界面新增的功能，包括：
1. Web Server 二进制路径配置
2. CBA 文件服务器
3. 站点部署配置（E3D 目录和 SurrealDB）

## 1. Web Server 配置

### Web Server 二进制路径

现在可以配置 Web Server 的可执行文件路径，方便在不同环境下使用。

**配置步骤：**

1. 进入"Web Server"页面
2. 在"Web Server 二进制路径"字段中输入路径，或点击"📁"按钮选择文件
3. 默认路径：`./target/release/web_server`
4. 点击"💾 保存配置"保存设置

**示例路径：**
- 开发环境：`./target/debug/web_server`
- 发布环境：`./target/release/web_server`
- 自定义路径：`/usr/local/bin/web_server`

### 启动 Web Server

配置完成后，点击"▶️ 启动 Web Server"按钮启动服务器。

**启动参数：**
- 监听地址：默认 `0.0.0.0`
- 监听端口：默认 `3000`
- 数据库路径：默认 `deployment_sites.sqlite`
- 静态文件目录：默认 `frontend/v0-aios-database-management`

## 2. CBA 文件服务器

CBA（Component-Based Architecture）文件服务器用于提供对 CBA 目录的 HTTP 访问。

### 配置 CBA 服务器

**配置步骤：**

1. 进入"Web Server"页面
2. 找到"CBA 文件服务器"配置区域
3. 配置以下参数：
   - **CBA 目录**：CBA 文件存储目录（点击"📁"选择）
   - **CBA 服务器端口**：HTTP 服务器监听端口（默认 8080）

**示例配置：**
```
CBA 目录: ./CBA
CBA 服务器端口: 8080
```

### 启动 CBA 服务器

1. 确保 CBA 目录存在
2. 点击"▶️ 启动 CBA 服务器"按钮
3. 服务器启动后，可通过 `http://localhost:8080` 访问 CBA 文件

**访问示例：**
```
http://localhost:8080/models/building.e3d
http://localhost:8080/textures/wall.png
http://localhost:8080/data/metadata.json
```

### 查看日志

CBA 服务器日志会显示在"CBA 服务器日志"区域，包括：
- 启动/停止状态
- 服务目录
- 访问请求
- 错误信息

## 3. 站点部署配置

新增的站点配置页面允许配置站点的 E3D 目录和 SurrealDB 数据库连接。

### 访问站点配置页面

点击左侧导航栏的"站点配置"进入站点管理页面。

### 创建站点

**步骤：**

1. 点击"➕ 添加站点"按钮
2. 填写基本信息：
   - **站点名称**（必填）：站点的显示名称
   - **所属环境**（必填）：选择关联的环境
   - **HTTP 地址**：站点的 HTTP 访问地址
   - **地区**：站点所在地区
   - **数据库编号**：逗号分隔的数据库编号列表
   - **备注**：站点的额外说明

3. 配置 E3D 目录：
   - **E3D 监听目录**：站点监听的 E3D 文件目录
   - 点击"📁"按钮选择目录

4. 配置 SurrealDB 连接：
   - **SurrealDB 主机**：数据库服务器地址（默认 localhost）
   - **SurrealDB 端口**：数据库端口（默认 8000）
   - **命名空间**：SurrealDB 命名空间（默认 default）
   - **数据库**：数据库名称（默认 default）
   - **用户名**：数据库用户名（默认 root）
   - **密码**：数据库密码

5. 点击"💾 保存"完成创建

### 配置示例

**示例 1：本地开发站点**
```
基本信息：
  站点名称: 本地测试站点
  所属环境: 开发环境
  HTTP 地址: http://localhost:3001
  地区: 北京
  数据库编号: 7999,8001,8002

E3D 配置：
  E3D 监听目录: /Users/username/projects/e3d_files

SurrealDB 配置：
  主机: localhost
  端口: 8000
  命名空间: dev
  数据库: test_db
  用户名: root
  密码: ********
```

**示例 2：生产环境站点**
```
基本信息：
  站点名称: 生产站点-上海
  所属环境: 生产环境
  HTTP 地址: http://192.168.1.100:3001
  地区: 上海
  数据库编号: 7999,8001,8002,8003

E3D 配置：
  E3D 监听目录: /data/e3d_production

SurrealDB 配置：
  主机: 192.168.1.200
  端口: 8000
  命名空间: production
  数据库: main_db
  用户名: admin
  密码: ********
```

### 编辑站点

1. 在站点列表中找到要编辑的站点
2. 点击"编辑"按钮
3. 修改配置信息
4. 点击"💾 保存"保存更改

### 测试站点连接

点击站点列表中的"测试"按钮，可以测试：
- HTTP 地址是否可访问
- SurrealDB 连接是否正常
- E3D 目录是否存在

### 删除站点

1. 点击站点列表中的"删除"按钮
2. 在确认对话框中点击"确认"
3. 站点将被删除

## 配置文件

所有配置会保存到 `DbOption.toml` 文件中，包括：

```toml
[web_server]
binary = "./target/release/web_server"
host = "0.0.0.0"
port = 3000
db_path = "deployment_sites.sqlite"
static_dir = "frontend/v0-aios-database-management"

[cba_server]
dir = "./CBA"
port = 8080

[sites]
# 站点配置存储在数据库中
```

## 故障排除

### Web Server 无法启动

**问题**：点击启动按钮后显示错误

**解决方案**：
1. 检查二进制文件路径是否正确
2. 确认文件具有执行权限：`chmod +x ./target/release/web_server`
3. 检查端口是否被占用
4. 查看日志了解详细错误信息

### CBA 服务器无法访问文件

**问题**：浏览器访问 CBA 文件返回 404

**解决方案**：
1. 确认 CBA 目录路径正确
2. 检查目录权限
3. 确认文件确实存在于 CBA 目录中
4. 查看 CBA 服务器日志

### 站点无法连接 SurrealDB

**问题**：测试连接失败

**解决方案**：
1. 确认 SurrealDB 服务已启动
2. 检查主机和端口配置
3. 验证用户名和密码
4. 检查网络连接和防火墙设置
5. 确认命名空间和数据库存在

### E3D 目录监听失败

**问题**：站点无法监听 E3D 目录

**解决方案**：
1. 确认目录路径正确
2. 检查目录权限
3. 确认目录存在
4. 检查磁盘空间

## 最佳实践

### Web Server 配置

1. **开发环境**：使用 debug 构建的二进制
2. **生产环境**：使用 release 构建的二进制
3. **定期备份**：备份数据库文件
4. **日志监控**：定期查看服务器日志

### CBA 服务器

1. **目录组织**：按类型组织 CBA 文件（models/、textures/、data/）
2. **访问控制**：考虑添加访问控制（未来功能）
3. **性能优化**：对大文件启用压缩
4. **定期清理**：删除不再使用的文件

### 站点配置

1. **命名规范**：使用清晰的站点名称（如"生产-北京-01"）
2. **环境隔离**：开发、测试、生产环境使用不同的配置
3. **密码安全**：使用强密码，定期更换
4. **备份配置**：定期导出站点配置
5. **文档记录**：记录每个站点的用途和配置

## 安全建议

1. **密码管理**：
   - 不要在配置文件中明文存储密码
   - 使用环境变量或密钥管理系统
   - 定期更换数据库密码

2. **网络安全**：
   - 使用防火墙限制访问
   - 启用 HTTPS（生产环境）
   - 限制 CBA 服务器的访问范围

3. **权限控制**：
   - 最小权限原则
   - 定期审查访问权限
   - 记录操作日志

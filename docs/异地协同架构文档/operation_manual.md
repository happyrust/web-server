### 操作按钮说明

| 按钮 | 功能 | 适用节点 |
|------|------|---------|
| 设为主节点 | 将当前节点标记为主节点 | 从节点 |
| 设为从节点 | 将当前节点标记为从节点 | 主节点 |
| 启动 Broker | 启动 MQTT Broker 服务 | 主节点 |
| 停止 Broker | 停止 MQTT Broker 服务 | 主节点 |
| 启动订阅 | 启动 MQTT Publisher + Subscriber | 所有节点 |
| 停止订阅 | 停止 MQTT Publisher + Subscriber | 所有节点 |
| 刷新 | 刷新页面数据 | 所有节点 |

## API 接口说明

### MQTT 控制接口

#### 获取订阅状态
```http
GET /api/mqtt/subscription/status
```

响应示例:
```json
{
  "status": "success",
  "is_subscription_running": true,
  "is_server_running": true,
  "mqtt_server_port": 1883,
  "location": "master-bj",
  "is_master_node": true,
  "node_role": "master"
}
```

#### 启动订阅
```http
POST /api/mqtt/subscription/start
Content-Type: application/json

{}
```

响应示例:
```json
{
  "status": "success",
  "message": "MQTT 订阅已启动"
}
```

#### 停止订阅
```http
POST /api/mqtt/subscription/stop
Content-Type: application/json
```

#### 启动 MQTT Broker (仅主节点)
```http
POST /api/sync/mqtt/start
Content-Type: application/json

{
  "port": 1883
}
```

#### 停止 MQTT Broker
```http
POST /api/sync/mqtt/stop
Content-Type: application/json
```

### 节点角色接口

#### 设为主节点
```http
POST /api/mqtt/node/set-master
Content-Type: application/json
```

#### 设为从节点
```http
POST /api/mqtt/node/set-client
Content-Type: application/json
```

### 监控接口

#### 获取节点列表
```http
GET /api/mqtt/nodes
```

响应示例:
```json
{
  "success": true,
  "nodes": [
    {
      "location": "master-bj",
      "node_name": "master-bj",
      "is_online": true,
      "messages_received": 15,
      "last_heartbeat": "2024-01-15T10:30:00Z"
    }
  ],
  "summary": {
    "total": 3,
    "online": 3,
    "offline": 0
  }
}
```

#### 获取消息列表
```http
GET /api/mqtt/messages?limit=100
```

## 运维操作

### 重启服务

```bash
# Windows
taskkill /F /IM web_server.exe
cargo run --bin web_server --features web_server

# Linux
pkill -f web_server
cargo run --bin web_server --features web_server
```

### 清理临时文件

```bash
# 清理 CBA 临时文件
rm -rf assets/temp/*

# 清理过期归档 (保留最近 7 天)
find assets/archives -mtime +7 -delete
```

### 数据库维护

```sql
-- 清理过期的 e3d_sync 记录 (保留最近 30 天)
DELETE FROM e3d_sync WHERE created_at < NOW() - INTERVAL 30 DAY;

-- 查看同步状态统计
SELECT 
  DATE(created_at) as date,
  COUNT(*) as total,
  SUM(CASE WHEN status = 'completed' THEN 1 ELSE 0 END) as completed
FROM e3d_sync
GROUP BY DATE(created_at)
ORDER BY date DESC
LIMIT 30;
```

### 备份与恢复

```bash
# 备份配置
cp DbOption.toml DbOption.toml.backup

# 备份 SQLite 数据库
cp deployment_sites.sqlite deployment_sites.sqlite.backup

# 备份 SurrealDB 数据
surreal export --ns <namespace> --db <database> backup.surql
```

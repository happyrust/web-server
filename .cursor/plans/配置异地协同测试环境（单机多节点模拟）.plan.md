# 配置异地协同测试环境（单机多节点模拟）

## 目标

在 `config/test-real/` 目录下创建两个独立的测试站点，分别配置数据库编号 1112 和 7000，用于单机模拟多节点异地协同测试。两个站点可以互相模拟文件更新和同步。

## 目录结构

```
remote-test-dir/test-real/
├── site-1112/              # 站点 1112 的完整运行环境
│   ├── DbOption.toml       # 站点 1112 的配置文件
│   ├── deployment_sites.sqlite  # SQLite 数据库
│   ├── assets/             # 资源目录
│   │   └── archives/       # 压缩包存储
│   ├── output/             # 输出目录
│   │   └── remote_sync/    # 同步文件存储
│   └── AvevaMarineSample/  # 项目文件（站点 1112 的副本）
│       └── ams000/
│           └── ams1112_0001/  # 数据库 1112 的文件
└── site-7000/              # 站点 7000 的完整运行环境
    ├── DbOption.toml       # 站点 7000 的配置文件
    ├── deployment_sites.sqlite  # SQLite 数据库
    ├── assets/
    │   └── archives/
    ├── output/
    │   └── remote_sync/
    └── AvevaMarineSample/  # 项目文件（站点 7000 的副本）
        └── ams000/
            └── ams7000_0001/  # 数据库 7000 的文件
```

## 实施步骤

### 1. 创建站点目录结构

- 创建 `config/test-real/site-1112/` 目录
- 创建 `config/test-real/site-7000/` 目录
- 在每个目录下创建 `assets/archives/` 和 `output/remote_sync/` 子目录

### 2. 创建站点 1112 配置文件

**文件**: `config/test-real/site-1112/DbOption.toml`

基于 `DbOption.toml` 和 `config/remote_file_sync_test/DbOption-bj.toml`，配置：

- `project_path = "D:/AVEVA/Projects/E3D2.1"`
- `included_projects = ["AvevaMarineSample"]`
- `project_name = "AvevaMarineSample"`
- `project_code = 1516`
- `location = "SITE1112"`
- `location_dbs = [1112]`
- `deployment_sites_sqlite_path = "deployment_sites.sqlite"`（相对路径）
- `mqtt_host = "127.0.0.1"`
- `mqtt_port = 1883`
- `file_server_host = "http://127.0.0.1:8081/assets/archives"`

### 3. 创建站点 7000 配置文件

**文件**: `config/test-real/site-7000/DbOption.toml`

配置：

- `project_path = "D:/AVEVA/Projects/E3D2.1"`
- `included_projects = ["AvevaMarineSample"]`
- `project_name = "AvevaMarineSample"`
- `project_code = 1516`
- `location = "SITE7000"`
- `location_dbs = [7000]`
- `deployment_sites_sqlite_path = "deployment_sites.sqlite"`
- `mqtt_host = "127.0.0.1"`
- `mqtt_port = 1883`
- `file_server_host = "http://127.0.0.1:8082/assets/archives"`

### 4. 初始化站点 1112 的 SQLite 数据库

**文件**: `config/test-real/site-1112/deployment_sites.sqlite`

使用 Rust 代码或 SQL 脚本创建：

- 表结构（参考 `src/bin/remote_sync_smoke_test.rs`）
- 环境记录：name="测试环境-1112", location="SITE1112", location_dbs="1112"
- 站点记录：name="站点-7000", location="SITE7000", http_host="http://127.0.0.1:8082/files", dbnums="7000"

### 5. 初始化站点 7000 的 SQLite 数据库

**文件**: `config/test-real/site-7000/deployment_sites.sqlite`

创建：

- 表结构

- 站点记录：name="站点-1112", location="SITE1112", http_host="http://127.0.0.1:8081/files", dbnums="1112"

### 6. 创建初始化脚本

**文件**: `scripts/test-real/init_test_env.ps1`

PowerShell 脚本，功能：

- 创建目录结构
- 生成配置文件（基于模板）
- 初始化 SQLite 数据库（调用 Rust 工具或直接执行 SQL）
- 验证配置

### 7. 创建启动脚本

**文件**:

- `scripts/test-real/start-site-1112.ps1`
- `scripts/test-real/start-site-7000.ps1`

每个脚本：

- 切换到对应站点目录
- 设置工作目录为站点目录
- 启动 web_server：`cargo run --bin web_server --features web_server -- --port 8081`（或 8082）

### 8. 创建配置说明文档

**文件**: `docs/TEST_REAL_ENV_SETUP.md`

包含：

- 目录结构
- 配置说明
- 启动步骤
- 测试流程（如何修改文件触发同步）
- 故障排查

## 关键配置说明

### 端口分配

- 站点 1112: HTTP 8081，文件接收 `/files`
- 站点 7000: HTTP 8082，文件接收 `/files`
- MQTT: 共享 127.0.0.1:1883

### 文件同步流程

1. 站点 1112 检测到数据库 1112 文件变化
2. 生成压缩包到 `site-1112/assets/archives/`
3. HTTP PUT 到站点 7000: `http://127.0.0.1:8082/files/{env}/{site}/UPLOAD/{file}`
4. 站点 7000 接收并存储
5. 反向流程同理

## 注意事项

1. 两个站点需在不同终端运行
2. 确保端口 8081、8082 未被占用
3. MQTT 服务器需在 1883 运行（可使用内置服务器）
4. 项目路径必须存在
5. SQLite 路径使用相对路径，相对于 DbOption.toml
6. 两个站点互相配置为对方的远程站点

## MQTT 服务器配置

### rumqttd.toml 关键配置：

```toml
[v4.1]
name = "v4-1"
listen = "0.0.0.0:1883"  # MQTT 标准端口
next_connection_delay_ms = 1
    [v4.1.connections]
    connection_timeout_ms = 60000
    max_payload_size = 20480
    max_inflight_count = 100
```

### 编译 MQTT 服务器：

- 使用 rumqtt submodule 或现有的 rumqttd-server
- 编译命令：`cargo build --release --bin rumqttd`
- 输出：`rumqtt/target/release/rumqttd` 或 `rumqttd-server/target/release/mqtt-server`

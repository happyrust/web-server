## 技术实现细节

### 架构设计
- **即时模式 GUI**: 使用 egui 的即时模式渲染，简化状态管理
- **异步 API 调用**: 所有 HTTP 请求使用 tokio 异步执行，避免阻塞 UI
- **状态管理**: 集中式状态管理，通过 AppState 共享数据
- **模块化设计**: 页面和组件独立封装，易于维护和扩展
- **中文字体支持**: 自动检测并加载系统中文字体，支持 Windows/macOS/Linux

### 关键技术点
1. **eframe Storage API**: 用于配置持久化
2. **egui Painter API**: 用于自定义画布绘制
3. **reqwest**: 异步 HTTP 客户端
4. **serde_json**: JSON 序列化和反序列化
5. **rfd**: 原生文件对话框

# Web Server 集成功能测试清单

## 测试环境准备

### 1. 编译项目
```bash
cargo build --bin egui_remote_sync --features gui --release
```

**预期结果**: ✅ 编译成功，无错误

### 2. 启动应用
```bash
cargo run --bin egui_remote_sync --features gui
```

**预期结果**: ✅ GUI 窗口打开，显示导航栏

## 功能测试

### Phase 1: 服务器生命周期管理

#### 测试 1.1: 服务器启动
**步骤**:
1. 点击左侧导航栏 "Web Server"
2. 确认初始状态显示 "⚪ 已停止"
3. 点击 "▶️ 启动" 按钮

**预期结果**:
- ✅ 状态变为 "🟢 运行中"
- ✅ 显示服务器地址（如 `http://0.0.0.0:3000`）
- ✅ 显示运行时长（如 `0s`）
- ✅ 日志显示 "正在启动嵌入式 Web Server..."
- ✅ 日志显示 "Web Server 已启动: http://0.0.0.0:3000"

#### 测试 1.2: 服务器停止
**步骤**:
1. 确认服务器处于运行状态
2. 点击 "⏹️ 停止" 按钮

**预期结果**:
- ✅ 状态变为 "⚪ 已停止"
- ✅ 日志显示 "正在停止 Web Server..."
- ✅ 日志显示 "Web Server 已停止"
- ✅ 启动按钮重新可用

#### 测试 1.3: 服务器重启
**步骤**:
1. 启动服务器
2. 点击 "🔄 重启" 按钮

**预期结果**:
- ✅ 服务器先停止
- ✅ 然后重新启动
- ✅ 状态最终为 "🟢 运行中"
- ✅ 运行时长重置

#### 测试 1.4: 配置修改
**步骤**:
1. 展开 "配置" 折叠面板
2. 修改监听端口（如改为 3001）
3. 重启服务器

**预期结果**:
- ✅ 配置可以修改
- ✅ 重启后使用新端口
- ✅ 地址显示更新为新端口

## 自动化测试脚本

### 快速功能测试
```bash
#!/bin/bash
# test_web_server.sh

echo "启动 GUI 应用..."
cargo run --bin egui_remote_sync --features gui &
GUI_PID=$!

sleep 5

echo "测试健康检查端点..."
curl -f http://localhost:3000/health || echo "❌ 健康检查失败"

echo "发送测试请求..."
for i in {1..10}; do
    curl -s http://localhost:3000/health > /dev/null
    echo "✅ 请求 $i 完成"
done

echo "测试不存在的路径..."
curl -s http://localhost:3000/nonexistent > /dev/null
echo "✅ 404 测试完成"

echo "清理..."
kill $GUI_PID

echo "测试完成！"
```

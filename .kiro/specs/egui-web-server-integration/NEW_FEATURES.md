# 新增功能说明

## 1. 自动获取本机 IP 地址

### 功能描述

系统现在会自动检测并显示本机的 IP 地址，而不是显示 `0.0.0.0`。这使得配置导出 URL 更加实用，可以直接在其他设备上访问。

### 实现原理

使用网络连接测试来确定本机使用的网络接口 IP 地址：

1. **主要方法**: 尝试连接到公共 DNS 服务器（8.8.8.8），获取本地使用的网络接口地址
2. **备用方法**: 使用 UDP socket 绑定来确定本地地址
3. **最终回退**: 如果以上方法都失败，使用 localhost (127.0.0.1)

### 使用场景

#### 场景 1: 服务器状态显示
```
服务器状态: 🟢 运行中
地址: http://192.168.1.100:3000  ← 显示实际的本机 IP
运行时长: 1m 23s
```

#### 场景 2: 配置导出
当点击"导出配置"时，生成的 URL 使用本机 IP：
```
http://192.168.1.100:3000/api/config/export
```

而不是：
```
http://0.0.0.0:3000/api/config/export  ← 这个 URL 在其他设备上无法访问
```

### 优势

1. **即用性**: 生成的 URL 可以直接在其他设备上使用
2. **便捷性**: 无需手动查找本机 IP 地址
3. **准确性**: 自动选择正确的网络接口

### 配置界面显示

在"配置"折叠面板中，会显示检测到的本机 IP：

```
配置
├── 监听地址: 0.0.0.0
├── 监听端口: 3000
└── 本机 IP: 192.168.1.100  ← 自动检测
```

## 2. 环境选择功能

### 功能描述

在配置导出时，可以选择导出特定环境的配置，或导出所有环境的配置。这对于多环境部署场景非常有用。

### 使用场景

#### 场景 1: 多环境部署

假设你有以下环境：
- 开发环境 (dev)
- 测试环境 (test)
- 生产环境 (prod)

你可以选择只导出"生产环境"的配置，分享给生产环境的其他站点。

#### 场景 2: 配置隔离

不同环境的配置可能包含不同的：
- MQTT 服务器地址
- 文件服务器配置
- 数据库连接信息
- 站点列表

通过选择特定环境，可以避免将开发环境的配置误导入到生产环境。

### 界面说明

#### 环境选择下拉框

```
配置管理
┌─────────────────────────────┐
│ 选择环境: [全部环境 ▼]      │ ℹ️
└─────────────────────────────┘
  ├── 全部环境
  ├── 开发环境
  ├── 测试环境
  └── 生产环境

[📤 导出配置] [📥 导入配置] [📱 生成二维码]
```

#### 信息提示（ℹ️ 按钮）

鼠标悬停在 ℹ️ 按钮上会显示：
```
选择要导出的环境。
选择'全部环境'将导出所有配置。
选择特定环境只导出该环境的配置。
```

### 导出行为

#### 选择"全部环境"
```
导出 URL: http://192.168.1.100:3000/api/config/export
包含内容:
  - 所有环境配置
  - 所有站点配置
  - 全局 MQTT 配置
  - 全局文件服务器配置
```

#### 选择特定环境（如"生产环境"）
```
导出 URL: http://192.168.1.100:3000/api/config/export?env_id=prod
包含内容:
  - 生产环境配置
  - 属于生产环境的站点配置
  - 生产环境的 MQTT 配置
  - 生产环境的文件服务器配置
```

### 日志记录

系统会在日志中记录导出的环境：

```
[15:30:45] 导出环境: 生产环境
[15:30:45] 配置导出 URL: http://192.168.1.100:3000/api/config/export?env_id=prod
[15:30:45] URL 已复制到剪贴板
```

或

```
[15:30:45] 导出所有环境
[15:30:45] 配置导出 URL: http://192.168.1.100:3000/api/config/export
[15:30:45] URL 已复制到剪贴板
```

### 二维码生成

生成的二维码也会包含环境参数：

- **全部环境**: 二维码包含 `http://192.168.1.100:3000/api/config/export`
- **特定环境**: 二维码包含 `http://192.168.1.100:3000/api/config/export?env_id=prod`

### API 参数

配置导出 API 支持以下查询参数：

| 参数 | 类型 | 说明 | 示例 |
|------|------|------|------|
| `env_id` | string | 环境 ID（可选） | `?env_id=prod` |
| `format` | string | 导出格式（可选） | `?format=json` 或 `?format=toml` |

可以组合使用：
```
http://192.168.1.100:3000/api/config/export?env_id=prod&format=toml
```

## 实现细节

### 代码结构

#### 新增模块
```
src/gui/embedded_server/network_utils.rs
├── get_local_ip()           # 获取本机 IP
├── get_all_local_ips()      # 获取所有本机 IP
└── format_server_address()  # 格式化服务器地址
```

#### WebServerPage 新增字段
```rust
pub struct WebServerPage {
    // ... 现有字段 ...
    
    // 环境选择
    selected_env_id: Option<String>,
    available_environments: Vec<(String, String)>, // (id, name)
    
    // 本机 IP
    local_ip: Option<IpAddr>,
}
```

### 更新环境列表

在应用中，需要调用 `update_environments` 方法来更新可用环境列表：

```rust
// 在 app.rs 或其他地方
let environments = vec![
    ("dev".to_string(), "开发环境".to_string()),
    ("test".to_string(), "测试环境".to_string()),
    ("prod".to_string(), "生产环境".to_string()),
];

web_server_page.update_environments(environments);
```

## 使用示例

### 示例 1: 导出生产环境配置

1. 在 Web Server 页面，选择环境下拉框
2. 选择"生产环境"
3. 点击"📤 导出配置"
4. URL 自动复制到剪贴板：`http://192.168.1.100:3000/api/config/export?env_id=prod`
5. 分享给生产环境的其他站点

### 示例 2: 生成二维码

1. 选择要导出的环境（或选择"全部环境"）
2. 点击"📱 生成二维码"
3. 扫描二维码获取配置 URL
4. 在移动设备或其他电脑上访问该 URL

### 示例 3: 导入配置

1. 从主站点获取配置导出 URL
2. 在从站点点击"📥 导入配置"
3. 粘贴 URL（如 `http://192.168.1.100:3000/api/config/export?env_id=prod`）
4. 点击"获取配置"预览
5. 确认导入

## 注意事项

### IP 地址检测

1. **网络要求**: 需要能够访问外部网络（用于检测本机 IP）
2. **多网卡**: 如果有多个网络接口，会选择默认路由使用的接口
3. **VPN**: 如果使用 VPN，可能会显示 VPN 接口的 IP

### 环境选择

1. **环境列表**: 需要先加载环境列表才能显示下拉框
2. **默认选择**: 默认选择"全部环境"
3. **持久化**: 环境选择不会保存，每次打开页面都需要重新选择

### 配置导出

1. **服务器状态**: 服务器必须处于运行状态才能访问导出 URL
2. **网络访问**: 其他设备需要能够访问本机的网络
3. **防火墙**: 确保防火墙允许访问配置的端口（默认 3000）

# Web Server 控制面板快速入门

## 快速启动

### 1. 编译项目
```bash
cargo build --bin egui_remote_sync --features gui --release
```

### 2. 运行 GUI 应用
```bash
cargo run --bin egui_remote_sync --features gui
```

或使用已编译的二进制：
```bash
./target/release/egui_remote_sync
```

## 使用指南

### 启动 Web Server

1. 在左侧导航栏点击 "Web Server"
2. 在服务器状态区域点击 "▶️ 启动" 按钮
3. 服务器将在默认地址 `http://0.0.0.0:3000` 启动
4. 状态显示为 "🟢 运行中"

### 配置服务器

点击 "配置" 展开配置选项：
- **监听地址**: 默认 `0.0.0.0`（所有网络接口）
- **监听端口**: 默认 `3000`

修改后需要重启服务器才能生效。

### 查看统计信息

控制面板显示三个统计卡片：

#### 请求统计（蓝色）
- 总请求数
- 成功请求数
- 失败请求数
- 成功率百分比

#### 连接统计（绿色）
- 当前活跃连接数
- 峰值连接数

#### 性能统计（橙色）
- 平均响应时间（毫秒）
- CPU 使用率
- 内存使用量（MB）

### 查看性能趋势

性能趋势区域显示：
- 请求数趋势（最近 60 个采样点，每 5 秒采样一次）
- 响应时间趋势

*注意：图表功能将在后续版本中添加，当前显示最新数值*

### 查看请求日志

请求日志表格显示最近 100 条请求：
- **时间**: 请求时间（HH:MM:SS）
- **方法**: HTTP 方法（GET, POST 等）
- **路径**: 请求路径
- **状态码**: HTTP 状态码（成功绿色，失败红色）
- **响应时间**: 请求处理时间（毫秒）
- **客户端**: 客户端 IP 地址

#### 日志操作
- **🔄 刷新**: 更新日志显示（自动刷新）
- **🗑️ 清空**: 清除所有日志记录

### 配置管理

#### 导出配置
1. 点击 "📤 导出配置" 按钮
2. 配置导出 URL 将自动复制到剪贴板
3. 分享 URL 给其他站点导入配置

#### 导入配置
1. 点击 "📥 导入配置" 按钮
2. 在对话框中输入主站点配置 URL
3. 点击 "获取配置" 预览配置
4. 点击 "确认导入" 完成导入

*注意：配置导入功能需要后端 API 支持*

#### 生成二维码
1. 点击 "📱 生成二维码" 按钮
2. 扫描二维码获取配置 URL
3. 点击 "复制 URL" 复制到剪贴板

*注意：二维码图片显示功能将在后续版本中添加*

### 停止服务器

1. 点击 "⏹️ 停止" 按钮
2. 服务器将优雅关闭（等待所有请求完成）
3. 状态显示为 "⚪ 已停止"

### 重启服务器

1. 点击 "🔄 重启" 按钮
2. 服务器将先停止，然后重新启动
3. 用于应用配置更改

## 自动刷新

控制面板会自动刷新：
- **UI 刷新**: 每秒刷新一次
- **指标采样**: 每 5 秒采样一次
- **系统信息**: 每秒更新一次

无需手动刷新即可看到最新数据。

## 故障排除

### 服务器启动失败

**问题**: 点击启动后显示错误

**可能原因**:
1. 端口已被占用
2. 权限不足（绑定 1024 以下端口需要 root 权限）
3. 网络配置问题

**解决方案**:
1. 更改端口号（使用 1024 以上的端口）
2. 检查是否有其他程序占用该端口
3. 使用 `127.0.0.1` 代替 `0.0.0.0`

### 统计信息不更新

**问题**: 统计卡片显示为 0

**可能原因**:
1. 服务器未启动
2. 没有收到任何请求

**解决方案**:
1. 确认服务器状态为 "运行中"
2. 发送测试请求到服务器
3. 等待自动刷新（每秒）

### 日志表格为空

**问题**: 请求日志表格显示 "暂无日志"

**可能原因**:
1. 服务器刚启动，还没有请求
2. 日志已被清空

**解决方案**:
1. 发送测试请求到服务器
2. 等待请求到达

## 性能建议

### 内存使用
- 请求日志最多保留 100 条
- 响应时间历史最多保留 1000 条
- 错误日志最多保留 100 条
- 指标历史最多保留 60 个数据点

这些限制确保内存使用可控。

### CPU 使用
- 指标收集使用原子操作，开销极小
- UI 刷新每秒一次，不会过度占用 CPU
- 系统监控每秒更新一次

### 网络
- 嵌入式服务器与 EGUI 在同一进程中
- 无需额外的网络通信
- 配置导入/导出需要网络连接

## 高级功能

### 自定义配置

编辑配置文件（将在后续版本中支持）：
```toml
[web_server]
host = "0.0.0.0"
port = 3000
max_connections = 1000
request_timeout_ms = 30000
```

### 性能调优

调整采样频率（代码级别）：
```rust
// 在 WebServerPage::render 中
if self.last_metrics_sample.elapsed() > std::time::Duration::from_secs(5) {
    // 修改为 10 秒采样一次
    // std::time::Duration::from_secs(10)
}
```

### 日志导出

将日志导出到文件（将在后续版本中支持）：
```bash
# 导出为 CSV
curl http://localhost:3000/api/logs/export?format=csv > logs.csv

# 导出为 JSON
curl http://localhost:3000/api/logs/export?format=json > logs.json
```

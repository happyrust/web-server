# 任务向导增强

## 📋 项目概述

为 EGUI 应用中的配置解析任务和模型生成任务创建统一的向导界面，参考 frontend 的 deploy-wizard 设计模式，提供更好的用户体验。

**状态**: 📝 规划中  
**优先级**: P1 (重要)  
**预计工期**: 5.5 天

---

## 🎯 目标

### 主要目标
1. **简化任务创建流程** - 通过分步骤向导降低使用门槛
2. **提高配置准确性** - 实时验证和友好提示减少错误
3. **统一用户体验** - 与 frontend 保持一致的交互模式
4. **支持批量操作** - 一次性创建多个任务

### 次要目标
1. 提供配置模板功能
2. 支持配置导入导出
3. 显示资源需求预估
4. 提供帮助和示例

---

## 🚀 核心功能

### 1. 数据解析任务向导

**4 个步骤**:
1. **项目扫描** - 自动发现 PDMS 项目
2. **项目选择** - 多选要解析的项目
3. **解析配置** - 配置解析参数
4. **预览确认** - 预览并创建任务

**特点**:
- 异步目录扫描，不阻塞 UI
- 支持批量选择项目
- 实时配置验证
- 资源需求预估

### 2. 模型生成任务向导

**4 个步骤**:
1. **数据源选择** - 选择已解析的数据
2. **生成选项** - 配置生成参数
3. **性能配置** - 设置性能参数
4. **预览确认** - 预览并创建任务

**特点**:
- 数据完整性检查
- 质量预设（快速/平衡/高质量）
- 性能参数优化建议
- 预计耗时显示

## 🏗️ 技术架构

### 核心组件

```
TaskWizardManager
├── WizardState (状态管理)
├── StepIndicator (步骤指示器)
├── NavigationButtons (导航按钮)
└── Step Components (步骤组件)
    ├── ProjectScanStep
    ├── ProjectSelectionStep
    ├── ConfigurationStep
    └── PreviewStep
```

### 关键技术

- **状态管理**: Rust struct + 所有权系统
- **异步处理**: tokio + channel
- **UI 框架**: EGUI
- **验证**: 实时验证 + 友好提示

## API 端点速查

| 端点 | 方法 | 用途 |
|------|------|------|
| `/api/mqtt/nodes` | GET | 获取 MQTT 节点状态 |
| `/api/mqtt/messages` | GET | 获取消息投递记录 |
| `/api/remote-sync/topology` | GET | 获取拓扑配置 |
| `/api/remote-sync/topology` | POST | 保存拓扑配置 |
| `/api/remote-sync/topology` | DELETE | 删除拓扑配置 |

## 数据刷新速查

| 数据类型 | 刷新间隔 | 来源 |
|---------|---------|------|
| 节点状态 | 5 秒 | MQTT 心跳 |
| 消息记录 | 5 秒 | MQTT 投递 |
| 拓扑配置 | 手动/5 秒 | SQLite 数据库 |
| 离线检测 | 30 秒 | 心跳超时 |

## 故障排查速查

| 问题 | 可能原因 | 快速检查 |
|------|---------|---------|
| 只显示一个节点 | 拓扑配置为空 | `curl /api/remote-sync/topology` |
| 连接线不显示 | 节点位置不匹配 | 检查控制台日志 |
| 订阅状态错误 | MQTT 客户端未更新 | 检查 `broker_connected_sub` |
| 节点不刷新 | 定时器失效 | 刷新浏览器页面 |

## 关键组件说明

### 1. SyncControlCenter (同步控制中心)
- **职责**: 全局任务队列管理、状态追踪、配置管理
- **位置**: `src/web_server/sync_control_center.rs`
- **核心方法**:
  - `start(env_id)` - 启动服务
  - `add_task()` - 添加同步任务
  - `get_next_task()` - 获取待处理任务
  - `complete_task()` - 完成任务
  - `spawn_worker()` - 启动后台工作线程

### 2. RemoteRuntime (运行时管理)
- **职责**: 管理 Watcher 和 MQTT 连接的生命周期
- **位置**: `src/web_server/remote_runtime.rs`
- **核心方法**:
  - `start_runtime(env_id)` - 启动运行时
  - `stop_runtime()` - 停止运行时

### 3. AiosDBManager (增量管理器)
- **职责**: 文件监听、增量检测、压缩打包
- **位置**: `src/data_interface/increment_manager.rs`
- **核心方法**:
  - `init_watcher()` - 初始化文件监听
  - `async_watch()` - 异步监听文件变化
  - `execute_incr_update()` - 执行增量更新
  - `poll_sync_e3d_mqtt_events_with_backoff()` - MQTT 订阅

### 4. process_sync_task (任务执行器)
- **职责**: 具体执行文件同步操作
- **位置**: `src/web_server/sync_control_center.rs:process_sync_task()`
- **核心逻辑**:
  - 解析目标位置
  - 本地文件复制或 HTTP 上传
  - 元数据更新
  - 错误处理

## 错误处理与重试机制

```
任务失败
    │
    ▼
检查 retry_count < max_retries
    │
    ├─[是]──▶ 增加 retry_count
    │         延迟 retry_delay_ms
    │         重新入队 (Pending)
    │
    └─[否]──▶ 标记为 Failed
              发送告警事件
              记录错误日志
```

## 并发控制

- **max_concurrent_syncs**: 默认 5 个并发任务
- **Worker 循环**: 每 500ms 检查一次新任务
- **监控任务**: 每 1s 更新一次状态

## 事件通知 (SSE)

通过 `SYNC_EVENT_TX` 广播通道发送以下事件:
- `Started` - 服务启动
- `Stopped` - 服务停止
- `SyncCompleted` - 同步完成
- `SyncFailed` - 同步失败
- `ProgressUpdate` - 进度更新
- `ConnectionChanged` - 连接状态变化
- `Alert` - 告警消息

前端通过 SSE 端点订阅这些事件实现实时监控。
